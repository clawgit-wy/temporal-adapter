## 3. 整体架构

### 3.1 manifest 权限（高危集）

- `<all_urls>`：host_permissions 与 content_scripts 均为全站
- `cookies` / `webRequest` / `declarativeNetRequest`：任意站点 Cookie 读写与请求改写
- `scripting` / `userScripts`：向页面注入任意代码
- `externally_connectable`：`matches: *://*/*`——**任何网页都可直接给扩展发消息**
- CSP 含 `wasm-unsafe-eval`

### 3.2 远程代码热更新机制

```
service_worker 启动
  → 读取本地 config/app-config.json（cdnHost / apiHost / toolsPluginToken）
  → GET  {apiHost}/plugin/api/common/loadVer          （版本检查）
  → GET  {apiHost}/plugin/api/common/loadConfigVer    （拦截器规则版本）
  → GET  {apiHost}/plugin/api/common/loadInjectedData （注入数据）
  → 存 chrome.storage.local（moduleVersionConfig / interceptorConfig 等）
  → 按版本从 {cdnHost}=cdn-v3.koudai89.com/v2_build 拉取模块：
      config/iframeHandler.js、config/pageHooks.js、config/app-*.js …
  → chrome.scripting.executeScript 注入目标页面
```

- 本地包内 `source/*.js` 仅是 CDN 拉取失败时的 **bundle 兜底**（`BUNDLE_CANDIDATES`）
- 模块注入前有依赖探测：jQuery / Vue / Element UI / Moment 未加载则先注入本地库
- `popup` 也是服务端渲染：请求 `plugin/api/index/transferPopup` 返回的 HTML 直接 `innerHTML`

### 3.3 运行时拓扑

```
[页面 MAIN world]  injected.js：钩 XHR/fetch/JSONP，按规则捕获 API 数据
       │ window.postMessage / CustomEvent(KDCMInterceptorData)
[页面 ISOLATED world]  content_script_loader_v3.js ↔ content_interceptor.js
       │ chrome.runtime.sendMessage
[Service Worker]  消息路由中心：注入/存储/IndexedDB/Cookie/请求头拦截器/远程配置
       │ HTTPS
[厂商后端]  p-api.koudai89.com（业务） / safe.koudai89.com（代理） / cdn-v3.koudai89.com（代码）
```

## 4. 核心组件

### 4.1 Service Worker（后台中枢）

消息路由覆盖（`case` 分支，行号见美化文件 L2145-L4130）：

| 类别 | 命令 |
|---|---|
| 存储 | `get/set storage`、`indexeddb_get/set/remove/clear/getAllKeys/getStats/cleanExpired/setMultiple`、`sessionStorage`、`chromeStorage` |
| 注入 | `injectToAllFrames/injectToFrame/injectStyleToAllFrames/findFrameByUrl/sendMessageToFrame`、`inject_script_to_main_world`、`inject_local_script/inject_code_script/inject_cdn_script`（样式同理） |
| 网络 | `ajax_data / get_data / post_data / get_text_data`、`run_in_background / all_in_background` |
| Cookie | `get_current_cookies / getCookies / setCookies / removeCookie / get_cookies_str` |
| 请求头拦截 | `add/remove/update/toggle/list/has/clear_all_request_header_interceptor`（基于 declarativeNetRequest 动态改请求头） |
| 拦截器数据 | `interceptor_store_data / interceptor_get_data` |
| 远程配置 | `check_config_update / force_update_config / clear_cache_and_refresh` |
| 拼多多劫持 | `pdd_set_hijack_flag / pdd_clear_hijack_flag / pdd_get_commit_detail_status / pdd_hijack_trace_append` |
| 其他 | `open_url / copy_text / chrome_tabs_call / uploadSingle/uploadMultiple/uploadLarge` |

### 4.2 content_script_loader_v3.js（页面桥协议）

ISOLATED world ↔ MAIN world ↔ Service Worker 三方桥，支持的消息类型：

| 类型 | 用途 |
|---|---|
| `KDCM_EVAL_REQUEST` | **在页面 MAIN world 执行任意代码** |
| `setCookies` | 写目标站 Cookie |
| `chrome_storage_get/set`、`chrome_tabs_call`、`chrome_runtime_sendMessage` | 扩展能力全量代理给页面 |
| `GET_EXTENSION_URL` / `INJECT_CODE` | 取扩展资源 URL / 注入代码 |
| `pdd_hijack_result` | 拼多多劫持结果回传 |
| `pdd_transform_request_body` | 让页面转换商品编辑请求体（180s 超时） |
| `pdd_send_modified_request` | 页面代发改写后的请求（30s 超时，保持 Anti-Content 有效） |
| `pdd_save_to_indexeddb` | 数据落库 |
| `pdd_proxy_api_request` | 经 `proxy_api_request` 走服务端代理 |

### 4.3 interceptor（通用 API 拦截引擎）

- 配置驱动：`script/interceptor/config.json` 定义 platforms → urlPatterns / apiRules / htmlCaptureRules / idExtractor
- `injected.js`（MAIN world）钩三层：
  - **XHR**：包 `open/send`，load 后读 `responseText`
  - **fetch**：clone response 读文本
  - **JSONP**：扫描 `mtopjsonp*` 全局回调 + MutationObserver 监听 `h5api.m.taobao.com / h5api.m.tmall.com` 的 script 标签，包装回调函数
- 捕获结果两条出路：`CustomEvent("KDCMInterceptorData")` → SW 存储；或写入页面隐藏 DOM（`kdcm-interceptor-data`，带 data-* 属性）供其他脚本消费
- storageKey 支持模板变量：`{itemId}/{timestamp}/{date}/{datetime}/{platform}/{random}/{url_hash}`
- 规则可远程更新（`UPDATE_INTERCEPTOR_CONFIG` 消息热替换）
- 内置示例规则：天猫发布 `excel/sku/exportSkuTemplate`（捕获请求+响应，按 `catId` 提取）

## 6. 关键业务流程

### 6.1 淘宝系（天猫）批量上品流程

来源：pageHooks.js L20-L94 + interceptor config

```
① 选类目        发布页 URL 带 catId（sell.publish.tmall.com/tmall/publish.htm?catId=xxx）
② 拿 SKU 模板   页面请求 GET excel/sku/exportSkuTemplate?templateType=excel&catId=xxx
                → 钩子捕获响应，存 window.tmall_sku_template_data
                  并写入隐藏 div.tmall_sku_template_hook（encodeURIComponent 后的 Excel）
③ 图片先行      1688 拉图 → 千牛/旺铺上传 → 拿 filePath
                （上传响应里 data.filePath 被捕获存 window.tmall_uploaded_file_path）
④ 导入 SKU      页面发起 importSkuTemplate 请求时，钩子改写 body：
                jsonBody.filePath 为空 → 自动填入 ③ 的 filePath
⑤ 提交发布      表单正常提交；beforeunload 已被拦截不会中断
```

要点：**图片必须先传拿 filePath，SKU 批量导入复用页面自己的 importSkuTemplate 接口**——不逆向签名、不构造新请求，全部复用页面原生调用链，这是该插件 stability 的关键设计。

### 6.2 1688 → 淘宝系图片搬运时序

```
1688 卖家已登录（picman.1688.com）
  → iframeHandler 注入相册页
  → JSONP 拉 album_puller_ajax.json 分页取图
  → 余量检查 al1688RotRemain（相册空间不够则清理/复用槽位）
  → 按 SKU/详情分组上传（uploadSlot 并发控制 + album timeout 保护）
  → 千牛或旺铺通道入库 → 返回淘宝系图片 URL/filePath
  → postMessage 通知发布页 iframe 使用
```

### 6.3 拼多多改价/商品编辑链路（双通道）

```
declarativeNetRequest 捕获 goodsCommit/action/edit 请求
  → SW pdd_hijack_flag 开启时劫持
  → 【转换】pdd_transform_request_body → 页面 MAIN world 改 SKU/价格
       （type1/type2 SKU 分类统计，summarizePddEditBody 做前后对比留痕 pdd_hijack_trace）
  → 【发送】二选一：
     A. 页面代发 sendPagePddEditRequest：页面 fetch 原站接口
        优点：Cookie/Anti-Content/风控环境天然有效
     B. 服务端代理 sendProxyRequestOnce →
        POST https://safe.koudai89.com/plugin/api/move/proxyRequest
        body 含 url/headers(cookie!)/data —— 用户 Cookie 上送第三方服务器
  → 结果回传（PDD_ERROR_CODE 分类：TRANSFORM_TIMEOUT / TRANSFORM_ERROR / API_BIZ …）
```

风险：通道 B 将商家登录态上送插件作者服务器。

## 8. 迁移实现要点与风险提示

### 8.1 可借鉴的设计模式

1. **配置化拦截引擎**：规则（matchType/urlPattern/storageKey 模板/TTL）与执行器分离，规则可热更——做平台数据采集的通用骨架
2. **复用页面原生调用链**：不构造新请求，钩现有接口改参数（importSkuTemplate 案例），规避签名/风控
3. **双通道发送**：优先页面代发（环境真实），服务端代理兜底
4. **主文档流桥协议**：MAIN/ISOLATED/SW 三层消息桥 + requestId + 超时分类错误码
5. **上传槽位控制**：图片批量上传的并发槽位与余量回收
6. **userScripts 按站点匹配注入**：PAGE_HOOKS_USER_SCRIPT_MATCHES 一份清单管全部发布页

### 8.2 合规/安全风险（商用前必读）

| 风险 | 事实 |
|---|---|
| 用户 Cookie 上送 | `safe.koudai89.com/plugin/api/move/proxyRequest` 携带 Cookie 头转发 |
| 远程代码下发 | MV3 Chrome 商店现行政策已禁止；企业内部分发需自担 |
| 任意代码执行 | `KDCM_EVAL_REQUEST` + `externally_connectable *://*/*`，任何网页可触达扩展能力 |
| 平台风控对抗 | anti_content 生成、验证码 SDK 内嵌属平台明令禁止，随平台升级持续失效 |
| 官方替代 | 淘宝 TOP：`taobao.item.add/update`、`taobao.item.sku.add`、`taobao.picture.upload`、`taobao.itemcats.get`；拼多多/抖音均有对应开放平台 |
