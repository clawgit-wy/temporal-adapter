## 文档分类与功能说明

### 一、Temporal 方案设计系列

本系列文档围绕 Temporal 分布式工作流引擎的引入方案，从业务论证到工程落地形成完整链路。

#### 1.1 Temporal业务应用方案介绍.md

| 属性 | 内容 |
|------|------|
| **功能分类** | 方案总纲 / 决策论证 |
| **版本** | 未标注 |
| **核心内容** | 全面论证引入 Temporal 解决门禁系统人员权限批量管理痛点的必要性与可行性。覆盖业务痛点（限流失控、重试复杂、长耗时等待、异步回调不可靠、OOM 风险）、解决方案、PoC 验证、XXL-JOB/Quartz 对比分析、架构设计、部署方案、实施路径、成本收益与风险评估 |
| **关键结论** | Temporal 与 XXL-JOB 不冲突可共存；简单定时任务用 XXL-JOB，复杂业务流程用 Temporal；优先迁移海康批量校验场景 |
| **版本信息** | Temporal Server 1.24.2, Web UI 2.28.0, Java SDK 1.24.0 |
| **交叉引用** | → `验证场景.md`（PoC 细化）, → `业务定时任务.md`（痛点四深入）, → `Temporal部署.md`（部署落地）, → `Temporal-WebUI二次开发与部署设计文档.md`（UI 工程化）, → `Hikvision_Batch_Adapter_Design.md`（被替代的传统方案） |
| **被引用** | ← `Temporal迁移技术分析报告.md`（分析依据） |

### 二、业务场景专题系列

#### 2.1 业务定时任务.md

| 属性 | 内容 |
|------|------|
| **功能分类** | 业务场景 / 技术方案 |
| **版本** | 未标注 |
| **核心内容** | 专题论证"访客预约入场前 10 分钟自动下发权限"这类定时需求如何用 Temporal 优雅实现。核心是 `Workflow.sleep()` 持久化定时器（休眠期间零资源占用）。含代码示例（VisitorAccessWorkflowImpl）、进阶场景（Signal 动态改期/取消）、与 XXL-JOB/Quartz 扫库方案对比 |
| **关键结论** | 用 `Workflow.sleep()` 一行代码替代 XXL-JOB 扫库 + MQ 延迟消息，整个生命周期由引擎 100% 保证可靠 |
| **交叉引用** | → `Temporal业务应用方案介绍.md`（痛点四的深入展开） |
| **被引用** | ← `Temporal迁移技术分析报告.md`（入厂备案/访客授权迁移方案依据） |

#### 2.2 验证场景.md

## 阅读建议

### 对于决策者
1. 先读 `Temporal业务应用方案介绍.md` 了解方案全貌与成本收益
2. 再读 `Temporal迁移技术分析报告.md` 第 1 章执行摘要和第 5 章优先级建议

### 对于架构师
1. 先读 `Temporal业务应用方案介绍.md` 理解业务痛点与架构设计
2. 读 `temporal二次开发及部署设计.md` 和 `Temporal-WebUI二次开发与部署设计文档.md` 了解部署架构
3. 读 `Temporal迁移技术分析报告.md` 了解现有系统全貌与迁移评估

### 对于开发工程师
1. 先读 `Temporal部署.md` 搭建本地环境
2. 读 `验证场景.md` 跑通 5 个 PoC 场景
3. 读 `业务定时任务.md` 理解 Workflow.sleep() 核心模式
4. 读 `Temporal迁移技术分析报告.md` 第 2-4 章了解具体迁移目标与实现方案

### 对于运维工程师
1. 读 `Temporal部署.md` 了解 Docker Compose 部署
2. 读 `Temporal-WebUI二次开发与部署设计文档.md` 了解四层分离生产部署
3. 读 `Temporal迁移技术分析报告.md` 第 5.3 节了解风险与应对
