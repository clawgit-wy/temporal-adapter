# 人员权限下发工作流完整指南

## 1. 系统概述

本系统基于 Temporal Workflow 引擎实现人员权限下发功能，通过 mokapi 模拟海康威视 FaceHandSet 第三方接口，完整演示从校验到发行的全流程。

### 1.1 架构组成

| 组件 | 说明 | 端口 |
|------|------|------|
| Temporal Server | 工作流调度引擎（本地 CLI 启动） | 7233 (gRPC) |
| Temporal UI | Web 管理界面（随 Server 启动） | 8280 |
| mokapi | 模拟海康 FaceHandSet 接口 | 19090 |
| demo-worker | Temporal Worker + REST API | 18093 |

### 1.2 工作流流程

```
用户请求 → DemoController/PermissionController → Temporal Workflow → Activity → mokapi
                                                              ↓
                                                        Temporal Server (调度)
                                                              ↓
                                                        Temporal UI (监控)
```

### 1.3 支持的操作类型

| 操作类型 | 说明 | 对应接口 |
|----------|------|----------|
| FACE_ISSUE | 人脸发行 | /Api/FaceHandSet/FaceIssue |
| FACE_MODIFY | 人脸改写 | /Api/FaceHandSet/FaceModify |
| DOOR_ISSUE | 卡发行 | /Api/FaceHandSet/DoorIssue |
| POWER_ADD | 增量增加权限 | /Api/FaceHandSet/FaceModifyBypowerType (powerType=0) |
| POWER_DELETE | 增量删除权限 | /Api/FaceHandSet/FaceModifyBypowerType (powerType=1) |

## 2. 快速启动（本地模式）

### 2.1 前置条件

| 依赖 | 版本要求 | 说明 |
|------|----------|------|
| JDK 8 | 1.8+ | demo-worker 编译运行 |
| JDK 17 | 17+ | mokapi 编译运行（Spring Boot 3.x 要求） |
| Maven | 3.6+ | 项目构建 |
| Temporal CLI | 最新版 | 本地启动 Temporal Server |

> **多版本 JDK 说明**: 如果机器上同时有 JDK 8 和 JDK 17，可以通过 `JAVA_HOME` 环境变量切换。建议先编译 mokapi（JDK 17），再编译 demo-worker（JDK 8），或使用 Maven Toolchains。

### 2.2 安装 Temporal CLI

```bash
# macOS
brew install temporal

# Linux/WSL
curl -sSf https://temporal.download/cli.sh | sh

# 验证安装
temporal --version
```

### 2.3 启动步骤

#### Step 1: 启动 Temporal Server

```bash
# 启动 Temporal Server（含 UI），使用本地 SQLite 存储
temporal server start \
  --port 7233 \
  --ui-port 8280 \
  --db-filename /tmp/temporal-dev.db \
  --log-level error

# 保持终端运行，或加 & 后台运行
temporal server start --port 7233 --ui-port 8280 --db-filename /tmp/temporal-dev.db &
```

验证 Temporal 启动:
```bash
temporal operator namespace describe default
# 或访问 http://localhost:8280 查看 UI
```

#### Step 2: 编译并启动 mokapi

```bash
cd mokapi

# 编译（需要 JDK 17）
mvn clean package -DskipTests

# 启动
java -jar target/mokapi-1.0.0.jar

# 或直接用 Maven 运行
mvn spring-boot:run
```

验证 mokapi 启动:
```bash
curl http://localhost:19090/Api/FaceHandSet/health
# 返回: {"status":"UP","service":"mokapi-permission-issue",...}
```

#### Step 3: 编译并启动 demo-worker

```bash
cd demo-worker

# 编译（需要 JDK 8）
mvn clean package -DskipTests -Pdev

# 启动
java -jar target/demo-worker-1.0.0.jar

# 或直接用 Maven 运行
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

验证 demo-worker 启动:
```bash
curl http://localhost:18093/api/permission/health
# 返回: {"status":"UP","service":"permission-worker",...}
```

#### Step 4: 验证全链路

```bash
# 访问 Temporal UI
open http://localhost:8280

# 测试人脸发行工作流
curl -X POST http://localhost:18093/api/permission/face-issue \
  -H "Content-Type: application/json" \
  -d '{"token":"CARD-001","staff":{"staffNo":"EMP-001","staffName":"测试用户"}}'
```

### 2.4 环境变量配置

demo-worker 支持以下环境变量:

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `TEMPORAL_ADDRESS` | 127.0.0.1:7233 | Temporal Server 地址 |
| `MOKAPI_URL` | http://localhost:19090 | mokapi 服务地址 |

```bash
# 示例：自定义地址
export TEMPORAL_ADDRESS=127.0.0.1:7233
export MOKAPI_URL=http://127.0.0.1:19090
java -jar target/demo-worker-1.0.0.jar
```

mokapi 支持以下环境变量:

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `MOKAPI_DEFAULT_DELAY_MS` | 0 | 全局延迟（毫秒） |
| `MOKAPI_ERROR_RATE` | 0.0 | 随机错误率（0.0~1.0） |
| `MOKAPI_SLOW_DELAY_MS` | 3000 | SLOW 关键字延迟（毫秒） |

## 4. Temporal CLI 命令

### 4.1 安装 Temporal CLI

```bash
# macOS
brew install temporal

# Linux/WSL
curl -sSf https://temporal.download/cli.sh | sh

# 验证安装
temporal --version
```

### 4.2 工作流管理命令

#### 查看所有工作流
```bash
# 列出所有工作流执行
temporal workflow list

# 按状态过滤
temporal workflow list --status RUNNING
temporal workflow list --status COMPLETED
temporal workflow list --status FAILED

# 限制返回数量
temporal workflow list --limit 20
```

#### 查看工作流详情
```bash
# 查看工作流执行详情
temporal workflow describe --workflow-id perm-face-issue-1234567890

# 查看工作流执行历史
temporal workflow show --workflow-id perm-face-issue-1234567890

# 以 JSON 格式输出
temporal workflow show --workflow-id perm-face-issue-1234567890 --output json
```

#### 查询工作流状态
```bash
# 查询自定义 QueryMethod (getStatus)
temporal workflow query --workflow-id perm-face-issue-1234567890 --query getStatus
```

#### 终止工作流
```bash
# 终止正在运行的工作流
temporal workflow terminate --workflow-id perm-face-issue-1234567890

# 终止并指定原因
temporal workflow terminate --workflow-id perm-face-issue-1234567890 --reason "手动终止测试"
```

#### 取消工作流
```bash
# 发送取消信号
temporal workflow cancel --workflow-id perm-face-issue-1234567890
```

#### 发送信号
```bash
# 发送自定义信号
temporal workflow signal --workflow-id perm-face-issue-1234567890 --name mySignal --input '"signal-data"'
```

## 5. mokapi 接口模拟配置

### 5.1 mokapi 配置说明

mokapi 配置位于 `mokapi/src/main/resources/application.yml`:

```yaml
server:
  port: 19090

mokapi:
  default-delay-ms: 0      # 全局延迟（毫秒），模拟网络延迟
  error-rate: 0.0            # 随机错误率（0.0~1.0），0表示不随机报错
  slow-delay-ms: 3000       # SLOW关键字触发的延迟（毫秒）
```

可通过环境变量覆盖:
```bash
MOKAPI_DEFAULT_DELAY_MS=500   # 所有接口延迟500ms
MOKAPI_ERROR_RATE=0.1          # 10%概率随机报错
MOKAPI_SLOW_DELAY_MS=5000      # SLOW关键字延迟5秒
```

### 5.2 模拟接口列表

| 接口 | 路径 | 方法 | 说明 |
|------|------|------|------|
| 发行校验 | /Api/FaceHandSet/CheckTokenState | POST | 检查卡号/人脸是否存在 |
| 人脸发行 | /Api/FaceHandSet/FaceIssue | POST | 人脸权限发行 |
| 人脸改写 | /Api/FaceHandSet/FaceModify | POST | 人脸权限修改 |
| 卡发行 | /Api/FaceHandSet/DoorIssue | POST | 卡权限发行 |
| 增量权限 | /Api/FaceHandSet/FaceModifyBypowerType | POST | 增量添加/删除设备权限 |
| 健康检查 | /Api/FaceHandSet/health | GET | 服务健康检查 |

### 5.3 关键字控制行为

通过在 `token` 或 `staffNo` 字段中包含特定关键字来控制 mokapi 响应行为:

| 关键字 | 行为 | 示例 |
|--------|------|------|
| `FAIL` | 返回业务失败（code=500） | token: "FAIL-CARD-001" |
| `ERROR` | 返回 HTTP 500 异常（触发重试） | staffNo: "ERROR-EMP-001" |
| `SLOW` | 延迟 3 秒返回 | token: "SLOW-CARD-001" |
| `TIMEOUT` | 延迟 30 秒返回 | staffNo: "TIMEOUT-EMP-001" |
| `NOTFOUND` | CheckTokenState 返回不存在 | token: "NOTFOUND-CARD-001" |
| 无关键字 | 正常成功响应 | token: "CARD-001" |

### 5.4 测试场景示例

#### 正常发行
```bash
curl -X POST http://localhost:19090/Api/FaceHandSet/CheckTokenState \
  -H "Content-Type: application/json" \
  -d '{"TokenType": 0, "Token": "CARD-001"}'
```
返回: `{"code":200, "msg":"卡号【CARD-001】存在发行信息...", "result":{...}}`

#### 校验不存在
```bash
curl -X POST http://localhost:19090/Api/FaceHandSet/CheckTokenState \
  -H "Content-Type: application/json" \
  -d '{"TokenType": 0, "Token": "NOTFOUND-001"}'
```
返回: `{"code":500, "msg":"操作失败", "result":null}`

#### 触发错误重试
```bash
curl -X POST http://localhost:18093/api/permission/face-issue \
  -H "Content-Type: application/json" \
  -d '{"token": "ERROR-001", "staff": {"staffNo": "ERROR-TEST", "staffName": "错误测试"}}'
```
工作流会重试 3 次后失败，可在 Temporal UI 中查看重试记录。

### 6.1 日志文件位置

```

└── mokapi-worker-calls.log               # Worker 调用记录（重要：记录每次 HTTP 请求/响应）

├── demo-worker-activity.log              # Activity 日志（mokapi 调用、心跳）
```

### 6.2 查看 mokapi 接口调用记录

`mokapi-worker-calls.log` 是最重要的调试日志，记录了每次 HTTP 请求/响应的完整信息:

```bash
# 实时查看 mokapi 调用日志
tail -f mokapi/logs/mokapi-worker-calls.log

grep "CheckTokenState" mokapi/logs/mokapi-worker-calls.log

# 查看错误响应
grep "500" mokapi/logs/mokapi-worker-calls.log

# 查看慢响应
grep "SLOW\|TIMEOUT" mokapi/logs/mokapi-worker-calls.log
```
