### 3.4 数据源说明

Worker 启动后连接两个**远程业务库**（定义在 [application-dev.yml](file:///Users/apple/Desktop/AdapterService/workers/building-access-worker/src/main/resources/application-dev.yml)）:

> ⚠️ 若本机无法访问上述远程库，Worker 仍会启动并注册到 Temporal，但同步 Activity 执行时会失败并重试。工作流编排逻辑仍可通过 Temporal 事件历史验证。

## 4. 测试海康数据同步工作流

工作流信息:

| 项 | 值 |
|----|-----|
| Workflow Type | `HikSyncWorkflow` |
| TaskQueue | `HIK_SYNC_TASK_QUEUE` |
| 方法 | `syncToHik(HkSyncRequest)` |
| Query | `getSyncProgress()` |

### 4.1 方式一：Temporal CLI

#### 4.1.1 增量同步（默认最近 123 分钟）

```bash
temporal workflow start \
  --task-queue HIK_SYNC_TASK_QUEUE \
  --type HikSyncWorkflow \
  --workflow-id hik-sync-incremental-001 \
  --input '[{"syncType":"INCREMENTAL","timeWindowMinutes":123,"batchSize":900}]'
```

#### 4.1.2 自定义时间窗口同步

```bash
temporal workflow start \
  --task-queue HIK_SYNC_TASK_QUEUE \
  --type HikSyncWorkflow \
  --workflow-id hik-sync-custom-001 \
  --input '[{"syncType":"INCREMENTAL","customStartTime":"2026-08-01 00:00:00","customEndTime":"2026-08-14 23:59:59","batchSize":500}]'
```

#### 4.1.3 全量同步

```bash
temporal workflow start \
  --task-queue HIK_SYNC_TASK_QUEUE \
  --type HikSyncWorkflow \
  --workflow-id hik-sync-full-001 \
  --input '[{"syncType":"FULL","customStartTime":"2020-01-01 00:00:00","customEndTime":"2026-08-14 23:59:59","batchSize":500}]'
```

#### 4.1.4 查询同步进度（QueryMethod）

```bash
temporal workflow query \
  --workflow-id hik-sync-incremental-001 \
  --query getSyncProgress
```

**进度状态值**: `INIT` → `CALCULATING_TIME_WINDOW` → `QUERYING_DATA_SOURCES` → `MERGING_DATA` → `PROCESSING_FACE_IMAGES` → `SYNCING_TO_HIK` → `COMPLETED` / `FAILED`

#### 4.1.5 查看工作流结果与事件历史

```bash
# 工作流概要（含结果）
temporal workflow describe --workflow-id hik-sync-incremental-001

# 完整事件历史
temporal workflow show --workflow-id hik-sync-incremental-001

# 仅查看结果（JSON）
temporal workflow result --workflow-id hik-sync-incremental-001
```

#### 4.1.6 使用 input-file（复杂参数）

```bash
cat > /tmp/hik-sync-input.json << 'EOF'
[{
  "syncType": "INCREMENTAL",
  "timeWindowMinutes": 60,
  "batchSize": 500,
  "parallelImageDownload": true,
  "maxParallelImages": 10
}]
EOF

temporal workflow start \
  --task-queue HIK_SYNC_TASK_QUEUE \
  --type HikSyncWorkflow \
  --workflow-id hik-sync-file-001 \
  --input-file /tmp/hik-sync-input.json
```

### 4.3 方式三：Demo Java Client

创建测试类，通过 Temporal Java SDK 直接启动工作流。

**文件路径**: `src/test/java/com/hik/worker/HikSyncWorkflowTest.java`

```java
package com.hik.worker;

import com.hik.worker.model.HkSyncRequest;
import com.hik.worker.model.HkSyncResult;
import com.hik.worker.workflow.HikSyncWorkflow;
import io.temporal.client.WorkflowClient;
import io.temporal.client.WorkflowOptions;
import io.temporal.serviceclient.WorkflowServiceStubs;
import io.temporal.serviceclient.WorkflowServiceStubsOptions;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.Disabled;

@Disabled("需先启动 Temporal Server 与 Worker，手动执行时移除 @Disabled")
public class HikSyncWorkflowTest {

    @Test
    public void startIncrementalSync() {
        WorkflowServiceStubs service = WorkflowServiceStubs.newConnectedServiceStubs(
                WorkflowServiceStubsOptions.newBuilder()
                        .setTarget("127.0.0.1:7233")
                        .build());
        WorkflowClient client = WorkflowClient.newInstance(service);

        HkSyncRequest request = HkSyncRequest.builder()
                .syncType("INCREMENTAL")
                .timeWindowMinutes(123)
                .batchSize(900)
                .build();

        WorkflowOptions options = WorkflowOptions.newBuilder()
                .setTaskQueue("HIK_SYNC_TASK_QUEUE")
                .setWorkflowId("hik-sync-test-" + System.currentTimeMillis())
                .build();

        HkSyncWorkflow workflow = client.newWorkflowStub(HikSyncWorkflow.class, options);

        System.out.println(">>> 启动海康增量同步工作流...");
        HkSyncResult result = workflow.syncToHik(request);

        System.out.println(">>> 同步完成:");
        System.out.println("    状态:        " + result.getStatus());
        System.out.println("    黑名单数:    " + result.getBlackListCount());
        System.out.println("    员工数:      " + result.getEmployeeCount());
        System.out.println("    备案数:      " + result.getRegisterCount());
        System.out.println("    访客数:      " + result.getVisitorCount());
        System.out.println("    去重后总数:  " + result.getTotalAfterDedup());
        System.out.println("    成功写入数:  " + result.getSuccessCount());
        System.out.println("    失败数:      " + result.getFailCount());
        if (result.getErrorMessage() != null) {
            System.out.println("    错误信息:    " + result.getErrorMessage());
        }
    }

    @Test
    public void startFullSync() {
        WorkflowServiceStubs service = WorkflowServiceStubs.newConnectedServiceStubs(
                WorkflowServiceStubsOptions.newBuilder()
                        .setTarget("127.0.0.1:7233")
                        .build());
        WorkflowClient client = WorkflowClient.newInstance(service);

        HkSyncRequest request = HkSyncRequest.builder()
                .syncType("FULL")
                .customStartTime("2020-01-01 00:00:00")
                .customEndTime("2026-08-14 23:59:59")
                .batchSize(500)
                .build();

        WorkflowOptions options = WorkflowOptions.newBuilder()
                .setTaskQueue("HIK_SYNC_TASK_QUEUE")
                .setWorkflowId("hik-sync-full-" + System.currentTimeMillis())
                .build();

        HkSyncWorkflow workflow = client.newWorkflowStub(HikSyncWorkflow.class, options);
        HkSyncResult result = workflow.syncToHik(request);
        System.out.println(">>> 全量同步结果: " + result);
    }
}
```

**运行测试**:

### 5.2 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `Worker 启动后 TaskQueue 无 Poller` | Worker 未连上 Temporal | 检查 `TEMPORAL_ADDRESS=127.0.0.1:7233`，确认 Docker 容器 7233 端口已映射 |
| `Activity 查询黑名单失败` | MySQL 远程库不可达 | 确认本机能访问 `10.66.229.187:33306`，或修改 `application-dev.yml` 指向本地 MySQL |
| `Activity 写入海康中间库失败` | PG 远程库不可达 | 确认本机能访问 `10.40.0.1:7092`，或修改配置指向本地 PG |
| `workflow start 报 input 反序列化失败` | JSON 格式错误 | input 必须是 JSON 数组 `[ {...} ]`，外层方括号不可省略 |
| `temporal CLI 连接被拒绝` | Temporal Server 未启动 | `docker compose ps` 确认 temporal-server 状态为 running |

## 附录 A: HkSyncRequest 字段说明

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| syncType | String | `INCREMENTAL`=增量, `FULL`=全量 | INCREMENTAL |
| timeWindowMinutes | int | 增量时间窗口（分钟） | 123 |
| customStartTime | String | 自定义开始时间 `yyyy-MM-dd HH:mm:ss` | - |
| customEndTime | String | 自定义结束时间 `yyyy-MM-dd HH:mm:ss` | - |
| batchSize | int | 批量写入大小 | 900 |
| parallelImageDownload | boolean | 是否并行下载图片 | false |
| maxParallelImages | int | 最大并行图片下载数 | 0 |

> 优先级: `customStartTime/customEndTime` > `timeWindowMinutes`

## 附录 B: HkSyncResult 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| syncType | String | 同步类型 |
| blackListCount | int | 黑名单数据数 |
| employeeCount | int | 员工台账数据数 |
| registerCount | int | 外来人员备案数据数 |
| visitorCount | int | 访客数据数 |
| totalAfterFilter | int | 过滤后数据数 |
| totalAfterDedup | int | 去重后数据数 |
| successCount | int | 成功写入数 |
| failCount | int | 失败数 |
| status | String | `COMPLETED` / `PARTIAL_FAILED` / `FAILED` |
| errorMessage | String | 错误信息 |

## 附录 C: 工作流执行链路

```
syncToHik(request)
  │
  ├─ Step 1: 计算时间窗口
  │
  ├─ Step 2: 并行查询 4 数据源（Async.function）
  │    ├─ queryBlackMessageList    (MySQL, 30s超时, 3次重试)
  │    ├─ queryEmployeeMessageList (MySQL, 30s超时, 3次重试)
  │    ├─ queryEnterRegisterList   (MySQL, 30s超时, 3次重试)
  │    └─ queryVisitorHairpinList  (MySQL, 30s超时, 3次重试)
  │
  ├─ Step 3: 合并结果
  │
  ├─ Step 4-5: 处理人脸图片 + 去重（120s超时, 2次重试）
  │    ├─ 过滤无效数据（jobNo/certificateNo/faceUrl/name 为空）
  │    ├─ URL 替换（mp.yutong.com → safetyimg.yutong.com）
  │    ├─ 图片下载 + Base64 编码
  │    └─ 按 certificateNo 去重
  │
  ├─ Step 6: 批量写入海康中间库（60s超时, 3次重试）
  │    ├─ batchPersonSave → tb_middle_person (UPSERT)
  │    └─ batchFaceSave   → tb_middle_face   (UPSERT)
  │
  └─ Step 7: 返回 HkSyncResult
```
