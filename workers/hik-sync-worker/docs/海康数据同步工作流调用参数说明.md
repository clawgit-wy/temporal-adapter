# 海康数据同步工作流调用参数说明

> **项目**: hik-sync-worker
> **工作流**: HikSyncWorkflow
> **更新日期**: 2026-08-19

---

## 1. 工作流注册信息

调用工作流前需了解的 Temporal 注册信息：

| 属性 | 值 | 来源 |
|------|-----|------|
| Workflow Type | `HikSyncWorkflow` | `@WorkflowInterface` 接口名 |
| TaskQueue | `HIK_SYNC_TASK_QUEUE` | `TemporalWorkerConfig.TASK_QUEUE_HIK_SYNC` |
| 工作流方法 | `syncToHik(HkSyncRequest)` | `@WorkflowMethod` |
| 进度查询方法 | `getSyncProgress()` | `@QueryMethod` |
| Namespace | `default` | 默认命名空间 |
| 最大并发 Activity | 10 | `WorkerOptions.maxConcurrentActivityExecutionSize` |

## 2. 请求参数（HkSyncRequest）

### 2.1 字段总览

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `syncType` | String | 否 | `INCREMENTAL` | 同步类型：`INCREMENTAL`=增量同步，`FULL`=全量同步 |
| `timeWindowMinutes` | int | 否 | `123` | 增量同步时间窗口（分钟），仅在不指定自定义时间时生效 |
| `customStartTime` | String | 否 | - | 自定义开始时间，格式 `yyyy-MM-dd HH:mm:ss` |
| `customEndTime` | String | 否 | - | 自定义结束时间，格式 `yyyy-MM-dd HH:mm:ss` |
| `batchSize` | int | 否 | `900` | 批量写入海康中间库的每批大小 |
| `parallelImageDownload` | boolean | 否 | `false` | 是否并行下载图片（**当前版本未启用**，预留字段） |
| `maxParallelImages` | int | 否 | `0` | 最大并行图片下载数（**当前版本未启用**，预留字段） |

> **注意**：`parallelImageDownload` 和 `maxParallelImages` 字段在模型中存在，但当前工作流实现中未使用，图片下载在 `processFaceImages` Activity 内串行处理。

### 2.2 时间窗口计算逻辑

工作流根据传入参数决定查询时间范围：

```
若 customStartTime 和 customEndTime 均非空:
    startTime = customStartTime
    endTime   = customEndTime
否则:
    endTime   = 当前时间
    startTime = 当前时间 - timeWindowMinutes 分钟（默认123分钟）
```

| 场景 | 推荐参数组合 |
|------|-------------|
| 增量同步（定时调度） | `syncType=INCREMENTAL`, `timeWindowMinutes=123` |
| 全量同步（首次/补数据） | `syncType=FULL`, `customStartTime` + `customEndTime` 指定范围 |
| 指定时间段补数据 | `syncType=INCREMENTAL`, `customStartTime` + `customEndTime` |

### 2.3 JSON 序列化格式

由于 `HkSyncRequest` 使用 Lombok `@Builder` + Jackson，JSON 格式如下（`non_null` 序列化，空值字段不输出）：

**增量同步（最简）**：

```json
{
  "syncType": "INCREMENTAL",
  "timeWindowMinutes": 123,
  "batchSize": 900
}
```

**全量同步（自定义时间范围）**：

```json
{
  "syncType": "FULL",
  "customStartTime": "2020-01-01 00:00:00",
  "customEndTime": "2026-08-19 23:59:59",
  "batchSize": 500
}
```

**完整字段示例**：

```json
{
  "syncType": "INCREMENTAL",
  "timeWindowMinutes": 60,
  "customStartTime": "2026-08-19 08:00:00",
  "customEndTime": "2026-08-19 12:00:00",
  "batchSize": 500,
  "parallelImageDownload": false,
  "maxParallelImages": 0
}
```

> **说明**：当同时传入 `customStartTime`/`customEndTime` 和 `timeWindowMinutes` 时，自定义时间优先，`timeWindowMinutes` 被忽略。

## 3. 返回结果（HkSyncResult）

### 3.1 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `syncType` | String | 同步类型（回显请求参数） |
| `blackListCount` | int | 黑名单数据查询数量 |
| `employeeCount` | int | 员工台账数据查询数量 |
| `registerCount` | int | 外来人员备案数据查询数量 |
| `visitorCount` | int | 访客数据查询数量 |
| `totalAfterFilter` | int | 过滤后减少的数据数量（合并总数 - 过滤后数量） |
| `totalAfterDedup` | int | 去重后的最终写入数量 |
| `successCount` | int | 成功写入海康中间库的数量 |
| `failCount` | int | 失败数（正常为0，异常时为1） |
| `status` | String | 状态：`COMPLETED` / `FAILED` |
| `errorMessage` | String | 错误信息（成功时为 null） |

### 3.2 JSON 响应示例

**成功**：

```json
{
  "syncType": "INCREMENTAL",
  "blackListCount": 5,
  "employeeCount": 120,
  "registerCount": 3,
  "visitorCount": 8,
  "totalAfterFilter": 4,
  "totalAfterDedup": 132,
  "successCount": 132,
  "failCount": 0,
  "status": "COMPLETED",
  "errorMessage": null
}
```

**无增量数据**：

```json
{
  "syncType": "INCREMENTAL",
  "blackListCount": 0,
  "employeeCount": 0,
  "registerCount": 0,
  "visitorCount": 0,
  "totalAfterFilter": 0,
  "totalAfterDedup": 0,
  "successCount": 0,
  "failCount": 0,
  "status": "COMPLETED",
  "errorMessage": "无增量数据"
}
```

**失败**：

```json
{
  "syncType": "INCREMENTAL",
  "blackListCount": 5,
  "employeeCount": 120,
  "registerCount": 3,
  "visitorCount": 8,
  "totalAfterFilter": 0,
  "totalAfterDedup": 0,
  "successCount": 0,
  "failCount": 1,
  "status": "FAILED",
  "errorMessage": "批量写入海康中间库失败: Connection refused"
}
```

### 3.3 状态值说明

| status | 含义 | 触发条件 |
|--------|------|----------|
| `COMPLETED` | 同步完成 | 正常完成或无增量数据 |
| `FAILED` | 同步失败 | 图片处理失败或批量写入失败 |

## 4. 进度查询（getSyncProgress）

通过 Temporal `@QueryMethod` 实时查询工作流执行进度，无需等待工作流结束。

**返回值**：`String` 类型，表示当前执行阶段。

| 进度值 | 含义 |
|--------|------|
| `INIT` | 初始化 |
| `CALCULATING_TIME_WINDOW` | 计算时间窗口 |
| `QUERYING_DATA_SOURCES` | 并行查询4个数据源 |
| `MERGING_DATA` | 合并数据 |
| `PROCESSING_FACE_IMAGES` | 处理人脸图片+去重 |
| `SYNCING_TO_HIK` | 批量写入海康中间库 |
| `COMPLETED` | 同步完成 |
| `COMPLETED_NO_DATA` | 无增量数据，正常结束 |
| `COMPLETED_NO_VALID_DATA` | 过滤后无有效数据，正常结束 |
| `FAILED_PROCESS_IMAGES` | 人脸图片处理失败 |
| `FAILED` | 同步失败 |

## 5. 调用方式

### 5.1 方式一：Java SDK（同步调用）

最常用的调用方式，阻塞等待工作流执行完毕并返回结果。

```java
import com.hik.worker.model.HkSyncRequest;
import com.hik.worker.model.HkSyncResult;
import com.hik.worker.workflow.HikSyncWorkflow;
import io.temporal.client.WorkflowClient;
import io.temporal.client.WorkflowOptions;
import io.temporal.serviceclient.WorkflowServiceStubs;
import io.temporal.serviceclient.WorkflowServiceStubsOptions;
import java.time.Duration;

// 1. 连接 Temporal Server
WorkflowServiceStubs service = WorkflowServiceStubs.newConnectedServiceStubs(
        WorkflowServiceStubsOptions.newBuilder()
                .setTarget("127.0.0.1:7233")
                .build(),
        Duration.ofSeconds(10));
WorkflowClient client = WorkflowClient.newInstance(service);

// 2. 构造请求参数
HkSyncRequest request = HkSyncRequest.builder()
        .syncType("INCREMENTAL")
        .timeWindowMinutes(123)
        .batchSize(900)
        .build();

// 3. 创建工作流 Stub
HikSyncWorkflow workflow = client.newWorkflowStub(
        HikSyncWorkflow.class,
        WorkflowOptions.newBuilder()
                .setTaskQueue("HIK_SYNC_TASK_QUEUE")
                .setWorkflowId("hik-sync-001")
                .build());

// 4. 同步调用（阻塞至完成）
HkSyncResult result = workflow.syncToHik(request);

System.out.println("状态: " + result.getStatus());
System.out.println("成功数: " + result.getSuccessCount());
```

### 5.2 方式二：Java SDK（异步启动）

异步启动工作流，不阻塞当前线程，适合外部触发场景。

```java
// 异步启动，立即返回
WorkflowClient.start(workflow::syncToHik, request);

// 后续可通过 WorkflowId 查询结果或进度
HikSyncWorkflow stub = client.newWorkflowStub(
        HikSyncWorkflow.class,
        WorkflowOptions.newBuilder()
                .setTaskQueue("HIK_SYNC_TASK_QUEUE")
                .setWorkflowId("hik-sync-001")
                .build());

// 查询进度
String progress = stub.getSyncProgress();

// 阻塞等待结果
HkSyncResult result = stub.syncToHik(request);  // 仅查询，不重复执行
// 或使用 WorkflowStub.fromTyped(stub).getResult(HkSyncResult.class);
```

### 5.3 方式三：CLI 工具（TemporalCliRunner）

通过 Maven 命令行调用，适合手动测试。

**启动工作流**：

```bash
# 增量同步（默认参数）
mvn exec:java -Dexec.mainClass=com.hik.worker.cli.TemporalCliRunner \
  -Dexec.args="start hik-sync-001"

# 增量同步（指定参数）
mvn exec:java -Dexec.mainClass=com.hik.worker.cli.TemporalCliRunner \
  -Dexec.args="start hik-sync-001 --syncType INCREMENTAL --timeWindowMinutes 60 --batchSize 500"

# 全量同步（自定义时间范围）
mvn exec:java -Dexec.mainClass=com.hik.worker.cli.TemporalCliRunner \
  -Dexec.args="start hik-sync-full-001 --syncType FULL --startTime '2020-01-01 00:00:00' --endTime '2026-08-19 23:59:59' --batchSize 500"
```

**CLI start 命令参数**：

| 参数 | 格式 | 默认值 | 说明 |
|------|------|--------|------|
| `<workflowId>` | 位置参数（第1个） | 无（必填） | 工作流唯一标识 |
| `--syncType` | `--syncType <值>` | `INCREMENTAL` | 同步类型 |
| `--timeWindowMinutes` | `--timeWindowMinutes <整数>` | `123` | 时间窗口（分钟） |
| `--startTime` | `--startTime <时间>` | - | 自定义开始时间 |
| `--endTime` | `--endTime <时间>` | - | 自定义结束时间 |
| `--batchSize` | `--batchSize <整数>` | `900` | 批量大小 |

**查询进度**：

```bash
mvn exec:java -Dexec.mainClass=com.hik.worker.cli.TemporalCliRunner \
  -Dexec.args="query hik-sync-001"
```

**查看工作流详情**：

```bash
mvn exec:java -Dexec.mainClass=com.hik.worker.cli.TemporalCliRunner \
  -Dexec.args="describe hik-sync-001"
```

**列出工作流**：

```bash
mvn exec:java -Dexec.mainClass=com.hik.worker.cli.TemporalCliRunner \
  -Dexec.args="list --workflowType HikSyncWorkflow"

# 按状态过滤
mvn exec:java -Dexec.mainClass=com.hik.worker.cli.TemporalCliRunner \
  -Dexec.args="list --status RUNNING"
```

### 5.4 方式四：Temporal tctl 命令

使用 Temporal 官方 CLI 工具 `tctl` 启动工作流。

```bash
# 启动工作流（JSON 参数）
tctl workflow start \
  --taskqueue HIK_SYNC_TASK_QUEUE \
  --workflowtype HikSyncWorkflow \
  --workflowid hik-sync-001 \
  --input '{"syncType":"INCREMENTAL","timeWindowMinutes":123,"batchSize":900}'

# 全量同步
tctl workflow start \
  --taskqueue HIK_SYNC_TASK_QUEUE \
  --workflowtype HikSyncWorkflow \
  --workflowid hik-sync-full-001 \
  --input '{"syncType":"FULL","customStartTime":"2020-01-01 00:00:00","customEndTime":"2026-08-19 23:59:59","batchSize":500}'

# 查询进度
tctl workflow query \
  --workflowid hik-sync-001 \
  --querytype getSyncProgress

# 查看工作流状态
tctl workflow describe \
  --workflowid hik-sync-001

# 列出工作流
tctl workflow list \
  --query "WorkflowType='HikSyncWorkflow' ORDER BY StartTime DESC"
```

### 5.5 方式五：Temporal Cron 定时调度

通过 Temporal Cron Schedule 实现定时自动同步。

```java
HkSyncRequest request = HkSyncRequest.builder()
        .syncType("INCREMENTAL")
        .timeWindowMinutes(123)
        .batchSize(900)
        .build();

HikSyncWorkflow cronWorkflow = client.newWorkflowStub(
        HikSyncWorkflow.class,
        WorkflowOptions.newBuilder()
                .setTaskQueue("HIK_SYNC_TASK_QUEUE")
                .setWorkflowId("hik-sync-cron")
                .setCronSchedule("0 */2 * * *")  // 每2小时执行
                .build());

WorkflowClient.start(cronWorkflow::syncToHik, request);
```

| 调度场景 | Cron 表达式 | 说明 |
|----------|------------|------|
| 高频同步 | `0 */2 * * *` | 每2小时（窗口=123分钟，有重叠覆盖） |
| 标准同步 | `0 0,6,12,18 * * *` | 每6小时 |
| 低频全量 | `0 0 2 * * ?` | 每天凌晨2点（配合 FULL 模式） |

## 8. 参数校验规则

工作流内部对请求参数的处理规则：

| 参数 | 校验逻辑 |
|------|----------|
| `syncType` | 为空时默认使用 `INCREMENTAL` |
| `timeWindowMinutes` | `<= 0` 时默认使用 `123` |
| `batchSize` | `<= 0` 时默认使用 `900`；Activity 内同样兜底 `900` |
| `customStartTime` + `customEndTime` | 两者均非空时优先使用自定义时间，忽略 `timeWindowMinutes` |
| `customStartTime` 或 `customEndTime` | 仅传一个时不生效，回退到 `timeWindowMinutes` 计算 |

> 工作流层不做参数强校验（不抛异常），均通过默认值兜底。
