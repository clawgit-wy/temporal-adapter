# 海康数据同步使用说明

> **项目**: hik-sync-worker
> **模块**: HikSyncWorkflow（海康数据同步工作流）
> **更新日期**: 2026-08-17

---

## 1. 功能概述

海康数据同步工作流（HikSyncWorkflow）负责将安保系统 MySQL 数据库中的人员/人脸增量数据同步到海康中间库 PostgreSQL，供海康人脸识别设备消费。

### 1.1 架构特点

| 维度 | 说明 |
|------|------|
| 架构 | Temporal Workflow + Activity |
| 数据查询 | **并行查询4类数据**（Async.function） |
| 图片处理 | Activity 内处理，支持 Temporal 重试 |
| 批量写入 | 900/批，带重试 |
| 失败处理 | **Activity 自动重试** |
| 进度跟踪 | **QueryMethod 实时查询进度** |
| 数据库访问 | Spring JdbcTemplate 双数据源 |
| 时间窗口 | **可配置**（请求参数 timeWindowMinutes） |

### 1.2 工作流信息

| 属性 | 值 |
|------|-----|
| 工作流接口 | `com.hik.worker.workflow.HikSyncWorkflow` |
| 实现类 | `com.hik.worker.workflow.impl.HikSyncWorkflowImpl` |
| TaskQueue | `HIK_SYNC_TASK_QUEUE` |
| 场景标识 | `hikSync` |
| 最大并发 | 10 |
| Activity | `HikSyncActivity`（6个方法） |
| 进度查询 | `@QueryMethod getSyncProgress()` |

## 3. API 接口

### 3.1 启动同步工作流

通过 Temporal WorkflowClient 启动工作流：

```java
// 创建请求
HkSyncRequest request = HkSyncRequest.builder()
    .syncType("INCREMENTAL")      // 增量同步
    .timeWindowMinutes(123)       // 时间窗口123分钟
    .batchSize(900)               // 批量大小900
    .build();

// 启动工作流
HikSyncWorkflow workflow = workflowClient.newWorkflowStub(
    HikSyncWorkflow.class,
    WorkflowOptions.newBuilder()
        .setTaskQueue("HIK_SYNC_TASK_QUEUE")
        .setWorkflowId("hik-sync-" + System.currentTimeMillis())
        .build());

HkSyncResult result = workflow.syncToHik(request);
```

### 3.2 查询同步进度

```java
String progress = workflow.getSyncProgress();
// 返回格式: INIT → CALCULATING_TIME_WINDOW → QUERYING_DATA_SOURCES → MERGING_DATA → PROCESSING_FACE_IMAGES → SYNCING_TO_HIK → COMPLETED / FAILED
```

### 3.3 请求参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| syncType | String | 是 | - | INCREMENTAL=增量同步, FULL=全量同步 |
| timeWindowMinutes | int | 否 | 123 | 增量同步的时间窗口(分钟) |
| customStartTime | String | 否 | - | 自定义开始时间 (yyyy-MM-dd HH:mm:ss) |
| customEndTime | String | 否 | - | 自定义结束时间 (yyyy-MM-dd HH:mm:ss) |
| batchSize | int | 否 | 900 | 批量写入大小 |

### 3.4 返回结果说明

| 字段 | 类型 | 说明 |
|------|------|------|
| syncType | String | 同步类型 |
| blackListCount | int | 黑名单数据数 |
| employeeCount | int | 员工台账数据数 |
| registerCount | int | 外来人员备案数据数 |
| visitorCount | int | 访客数据数 |
| totalAfterFilter | int | 过滤后总数据数 |
| totalAfterDedup | int | 去重后总数据数 |
| successCount | int | 成功写入数 |
| failCount | int | 失败数 |
| status | String | 状态: COMPLETED/PARTIAL_FAILED/FAILED |
| errorMessage | String | 错误信息 |

## 6. 定时调度配置

推荐通过 Temporal 定时工作流或外部 Cron 触发：

### 方式1: Temporal Cron Workflow（推荐）

```java
HikSyncWorkflow cronWorkflow = workflowClient.newWorkflowStub(
    HikSyncWorkflow.class,
    WorkflowOptions.newBuilder()
        .setTaskQueue("HIK_SYNC_TASK_QUEUE")
        .setWorkflowId("hik-sync-cron")
        .setCronSchedule("0 */2 * * *")  // 每2小时
        .build());

WorkflowClient.start(cronWorkflow::syncToHik, request);
```

### 推荐调度频率

| 场景 | Cron 表达式 | 说明 |
|------|------------|------|
| 高频同步 | `0 */2 * * *` | 每2小时（时间窗口=123分钟，有重叠覆盖） |
| 标准同步 | `0 0,6,12,18 * * *` | 每6小时 |
| 低频同步 | `0 0 2 * * ?` | 每天凌晨2点（配合 FULL 模式） |

### 7.3 常见问题排查

| 问题 | 可能原因 | 排查方式 |
|------|----------|----------|
| 查询数据为空 | 时间窗口内无更新数据 | 检查 MySQL 中 update_time 是否在窗口内 |
| 图片下载失败 | 图片URL不可访问或网络超时 | 查看 Activity 重试日志，检查 URL 代理映射 |
| PostgreSQL写入失败 | 连接异常或字段约束冲突 | 检查 PG 连接配置，查看 ON CONFLICT 字段 |
| 工作流超时 | 数据量过大或图片处理慢 | 增大 Activity StartToCloseTimeout 或减小 batchSize |
| 访客数据未同步 | vendor_state 不在允许列表 | 确认 vendor_state IN (1,5,8,9,10,11) |
