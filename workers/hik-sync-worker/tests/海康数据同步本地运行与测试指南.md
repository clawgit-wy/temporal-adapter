# 海康数据同步本地运行与测试指南

> **项目**: hik-sync-worker
> **场景**: hikSync（海康数据同步）
> **更新日期**: 2026-08-17
> **适用环境**: macOS 本地开发

---

## 1. 环境准备

| 依赖 | 最低版本 | 验证命令 |
|------|---------|---------|
| JDK | 8+ | `java -version` |
| Maven | 3.6+ | `mvn -version` |
| Docker Desktop | 最新 | `docker version` |
| Temporal CLI | 1.0+ | 可选，见下方替代方案 |

> **国内网络环境说明**：若无法从 GitHub 下载 `temporal` CLI，可跳过安装，使用项目内置的 **Java CLI 工具**（`com.hik.worker.cli.TemporalCli`）替代。


- PostgreSQL: `localhost:5432`（Temporal 内部存储，非业务库）

## 3. 本地运行 Worker

### 3.1 启动 Worker

```bash
cd /Users/apple/Desktop/AdapterService/workers/hik-sync-worker

WORKER_SCENARIOS=hikSync \
TEMPORAL_ADDRESS=127.0.0.1:7233 \
mvn spring-boot:run -Pdev
```

### 3.2 验证 Worker 已注册

日志中出现以下行即表示成功:

```
海康同步Worker已注册, taskQueue: HIK_SYNC_TASK_QUEUE
WorkerFactory 已启动, 场景: [hikSync]
```

### 3.3 数据源说明

Worker 启动后连接两个**远程业务库**:

| 数据源 | 地址 | 用途 |
|--------|------|------|
| MySQL | `10.66.229.187:33306/safety` | 查询安保系统增量数据（黑名单/员工/备案/访客） |
| PostgreSQL | `10.40.0.1:7092/ctm02brss_ctm02brssdb` | 写入海康中间库（tb_middle_person / tb_middle_face） |

> ⚠️ 若本机无法访问上述远程库，Worker 仍会启动并注册到 Temporal，但同步 Activity 执行时会失败并重试。

## 4. 测试海康数据同步工作流

工作流信息:

| 项 | 值 |
|----|-----|
| Workflow Type | `HikSyncWorkflow` |
| TaskQueue | `HIK_SYNC_TASK_QUEUE` |
| 方法 | `syncToHik(HkSyncRequest)` |
| Query | `getSyncProgress()` |

### 4.1 方式一：Java CLI 工具（推荐）

#### 4.1.1 增量同步

```bash
mvn compile exec:java -Pdev \
  -Dexec.args="start hik-sync-001 --syncType INCREMENTAL --timeWindowMinutes 123 --batchSize 900"
```

#### 4.1.2 自定义时间窗口同步

```bash
mvn compile exec:java -Pdev \
  -Dexec.args="start hik-sync-custom-001 --syncType INCREMENTAL --startTime 2026-08-01 00:00:00 --endTime 2026-08-14 23:59:59 --batchSize 500"
```

#### 4.1.3 全量同步

```bash
mvn compile exec:java -Pdev \
  -Dexec.args="start hik-sync-full-001 --syncType FULL --startTime 2020-01-01 00:00:00 --endTime 2026-08-14 23:59:59 --batchSize 500"
```

#### 4.1.4 查询同步进度

```bash
mvn compile exec:java -Pdev \
  -Dexec.args="query hik-sync-001 getSyncProgress"
```

**进度状态值**: `INIT` → `CALCULATING_TIME_WINDOW` → `QUERYING_DATA_SOURCES` → `MERGING_DATA` → `PROCESSING_FACE_IMAGES` → `SYNCING_TO_HIK` → `COMPLETED` / `FAILED`

#### 4.1.5 查看工作流详情

```bash
mvn compile exec:java -Pdev \
  -Dexec.args="describe hik-sync-001"
```

#### 4.1.6 列出工作流

```bash
mvn compile exec:java -Pdev \
  -Dexec.args="list --workflowType HikSyncWorkflow"
```

### 4.2 方式二：Temporal CLI（可选）

```bash
# 增量同步
temporal workflow start \
  --task-queue HIK_SYNC_TASK_QUEUE \
  --type HikSyncWorkflow \
  --workflow-id hik-sync-incremental-001 \
  --input '[{"syncType":"INCREMENTAL","timeWindowMinutes":123,"batchSize":900}]'

# 查询进度
temporal workflow query \
  --workflow-id hik-sync-incremental-001 \
  --query getSyncProgress

# 查看详情
temporal workflow describe --workflow-id hik-sync-incremental-001
```

### 4.3 方式三：单元测试

```bash
# 移除 @Disabled 注解后执行:
mvn test -Dtest=HikSyncWorkflowTest#startIncrementalSync -Pdev
```

## 6. 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `Worker 启动后 TaskQueue 无 Poller` | Worker 未连上 Temporal | 检查 `TEMPORAL_ADDRESS=127.0.0.1:7233`，确认 Docker 容器 7233 端口已映射 |
| `Activity 查询黑名单失败` | MySQL 远程库不可达 | 确认本机能访问 `10.66.229.187:33306`，或修改 `application-dev.yml` 指向本地 MySQL |
| `Activity 写入海康中间库失败` | PG 远程库不可达 | 确认本机能访问 `10.40.0.1:7092`，或修改配置指向本地 PG |
| `workflow start 报 input 反序列化失败` | JSON 格式错误 | input 必须是 JSON 数组 `[ {...} ]`，外层方括号不可省略 |
| `temporal CLI 连接被拒绝` | Temporal Server 未启动 | `docker compose ps` 确认 temporal-server 状态为 running |

## 附录: 工作流执行链路

```
syncToHik(request)
  │
  ├─ Step 1: 计算时间窗口
  │
  ├─ Step 2: 并行查询 4 数据源（Async.function）
  │    ├─ queryBlackMessageList    (MySQL, 30s超时, 3次重试)
  │    ├─ queryEmployeeMessageList (MySQL, 30s超时, 3次重试)
  │    ├─ queryEnterRegisterList   (MySQL, 30s超时, 3次重试)
  │    └─ queryVisitorHairpinList  (MySQL, 30s超时, 3次重试)
  │
  ├─ Step 3: 合并结果
  │
  ├─ Step 4-5: 处理人脸图片 + 去重（120s超时, 2次重试）
  │    ├─ 过滤无效数据（jobNo/certificateNo/faceUrl/name 为空）
  │    ├─ URL 替换（mp.yutong.com → safetyimg.yutong.com）
  │    ├─ 图片下载 + Base64 编码
  │    └─ 按 certificateNo 去重
  │
  ├─ Step 6: 批量写入海康中间库（60s超时, 3次重试）
  │    ├─ batchPersonSave → tb_middle_person (UPSERT)
  │    └─ batchFaceSave   → tb_middle_face   (UPSERT)
  │
  └─ Step 7: 返回 HkSyncResult
```
